### Gate Status → What You Can Do

| Status | Dashboard | Products | Action |
|:---:|:---|:---|:---|
| ⬜ **Not added** | Amber banner: "Add bank details" | 🔒 Add button → Bank form | Go to Profile → Bank Details |
| 🟡 **Pending** | Yellow banner: "Under review" | 🔒 Blocked | Wait or contact admin |
| 🟢 **Verified** | No banner — you're good! | ✅ Full access | Start selling! |
| 🔴 **Rejected** | Red banner: "Update required" | 🔒 Blocked + reason shown | Fix details → resubmit |

```
     │
```


### ⚠️ Rejection Blacklist

```
  🔴 Reject same customer 5× in 1 hour
      │
      ▼
  🚫 ACCOUNT SUSPENDED
     Forced logout with countdown
     Contact admin to unblock
```

## 🧭 Screen Map

```
📱 Business Owner App
 ├── 📝 Register ──────── OTP → Society + Shop name + Shop type
 ├── ⏳ Pending ──────── "Application Received" (waiting for admin)
 ├── 📊 Dashboard ──────── Stats, revenue, quick actions, gate banners
 ├── 📦 Products ───────── Add/edit/toggle, name + bank gate
 ├── 🛒 Orders ─────────── Accept/reject/track, assign rider
 ├── 🎫 Promos ─────────── Create coupon codes
 └── ⚙️  Profile ──────────┐
      ├── ✏️  Edit Name (tap to edit inline)
      ├── 🏪 Business info
      ├── 🏦 Bank Details
      ├── 🛵 Delivery Partners
      ├── ⚙️  Settings (fees, timings, tags)
      └── 🔑 Change Password
```
